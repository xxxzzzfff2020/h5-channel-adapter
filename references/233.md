# 233 Leyuan H5

Based on two independent game ports, reviewed 2026-09-22. Listing sizes came from creator-console fields supplied for those projects; recheck the current form. This is 233 H5, not the native 233 Workshop/Pocket Ark product.

## Capabilities and rewards

- The established profile has no platform cloud save: remove TapTap cloud calls, automatic sync, restore UI and cloud promises. Preserve local autosave, offline progress, backups, recovery, local achievements and visual feedback. The sample scope does not prove other capabilities are permanently unavailable.
- IAA script: `https://cdn.233xyx.com/h5ad/metah5ad_v1.min.js`, ordinary script, global `MetaH5Ad`. Availability of the script is not a real-ad test.
- Use `MetaH5Ad.isAdSupport(1, callback)` and `MetaH5Ad.showAd(1, callback)`. This interface has no frontend AppID parameter; backend application creation, host binding and test access still matter.
- Award only for normalized `code === 0 && data.status === 4`. Display, click, close, skip, failure, timeout and unknown states do not earn rewards. Compatibility with old payloads needs actual evidence, not a generic `success: true` check.
- Native callbacks lack transaction IDs. Deduplicate requests/receipts and quarantine cancelled/timed-out callbacks until the real close lifecycle is resolved. Prevent late callbacks from rewarding a new request. Do not copy a sample timeout blindly.
- Preserve transactional reward persistence: completed ads with failed disk writes must retry without duplicate rewards or requiring another ad. Restore pause/audio state; ordinary gameplay should work when SDK is unavailable.

## Build and materials

ZIP root contains `index.html`; check the actual ZIP CRC, paths and file hashes. Package game media locally. Established external-script domains were official HTTPS `*.233leyuan.com` and `*.233xyx.com`; use exact verified URLs and real domain boundaries, never substring matches. Do not insert an invented user-SDK URL. IAA is an ordinary script; a separately required user SDK may use modules—verify its actual documentation.

Real SDK startup matters: an SVG helper previously failed on dynamic `<svg>` without the SVG XML namespace. Mock-only tests missed it. Exclude TapTap SDK/cloud calls, unrelated IDs and QA entry points; preserve licenses and the existing build system.

Use the shared material rules: icon, 16:9 and 16:13 home images, 4–5 details, description/one-liner/recommendation, composite promotional+gameplay video and cover. A portrait detail hero needs its own composition; do not reuse the 16:13 home image as a 9:16 screenshot.

Complete local work first. Request only missing ad/user-SDK configuration or test access actually required. The established IAA interface needs no frontend SecretKey. Test completed/closed ads, saves, background recovery and the minimum device in the real host.
