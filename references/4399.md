# 4399 H5 minigames

Use `window.h5api`, not the H5 page-game `window.H5API`. Official raw ad/save/package documents were reviewed 2026-09-22. Listing sizes come from prior creator forms; some limits remain unknown in the machine rules.

## SDK and configuration

Official script: `https://h.api.4399.com/h5mini-2.0/h5api-interface.php`, loaded once in the body as documented. Do not call an old version the latest without checking.

| Area | Adapter rule |
| --- | --- |
| AppID | A new game's own ID; required for the established release-candidate configuration, not phase-one local preparation |
| Ads | `h5api.playAd(callback)`; 10000 is start, only 10001 earns the reward |
| Saves | `h5api.save({type:'read'/'write', more:false, title, data})`; verify permissions and responses |
| Writes | Must be user-triggered; no automatic platform writes; at least 30 seconds apart |
| Concurrency | Samples shared a 30-second cooldown and busy lock across reads/writes; this is a conservative implementation, not a universal read restriction |
| Ranking | Enable only when needed; obtain rankId, score meaning/range/order; reject out-of-range values rather than silently clamping |
| Achievements/haptics | No verified API in these cases; hide/no-op platform calls, retain local achievements and visual feedback |

Validate game, channel, schema/version and integrity before restoring; show a candidate and require player choice before replacing progress, keeping a backup. Reject wrong-game, future and test saves. Warn before overwriting cloud data. Guest success does not establish account-linked cross-device storage. Desktop cloud-save UI was hidden in a sample due to unreliable bridging; that is a fallback strategy requiring host verification, not a platform-wide fact.

## Container and delivery

The iframe may disable outer scrolling. Use a real inner scroll region (`min-height:0; overflow-y:auto`), in-layout bottom controls and safe-area/dynamic-height handling. Use `touch-action:pan-y` in lists and scope gesture restrictions to the game area; do not disable all scrolling.

ZIP root is `index.html`. Exclude environment files, secrets, test fixtures, `.DS_Store` and `__MACOSX`. Verify [FAQ](https://open.4399.cn/docs/h5mini/faq.md) extensions and paths; a sample checker omitted the allowed `data` extension. Package resources locally/inline except verified official links. Do not misclassify an SVG namespace URI as an external resource.

Shared rules include a 124×124 PNG icon, 300×200 JPG promotional image, 1080×1920 JPG video cover and description/controls of at most 300 characters each. Use the game's true orientation; a historical 402×874 portrait registration is not universal.

Produce promotional/brand + real-gameplay video. 1920×1080 H.264/AAC is the workflow export default, not a verified platform limit. Video duration/size and screenshot count remain unverified; never reuse 233's 500 MB limit. Optional 4–5 screenshot preparation is a studio convention.

After local preparation ask for AppID, ad/save permissions, rank configuration only if needed, then the upload test URL. No general frontend SecretKey requirement is established. Prioritize Xiaomi 8 / Android 10 in the required host (historically QQ), then other required browsers.
