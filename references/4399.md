# 4399 H5 minigames

Use `window.h5api`, not the H5 page-game `window.H5API`. Check the current official SDK and creator-console requirements. Unspecified limits remain explicit in the shared material rules.

## SDK and configuration

Official script: `https://h.api.4399.com/h5mini-2.0/h5api-interface.php`, loaded once in the body as documented. Do not call an old version the latest without checking.

| Area | Adapter rule |
| --- | --- |
| AppID | A new game's own ID; required for release-candidate configuration, not phase-one local preparation |
| Ads | `h5api.playAd(callback)`; 10000 is start, only 10001 earns the reward |
| Saves | `h5api.save({type:'read'/'write', more:false, title, data})`; verify permissions and responses |
| Writes | Must be user-triggered; no automatic platform writes; at least 30 seconds apart |
| Concurrency | Serialize pending requests; apply the documented write interval without inventing a universal read cooldown |
| Ranking | Enable only when needed; obtain rankId, score meaning/range/order; reject out-of-range values rather than silently clamping |
| Achievements/haptics | Confirm current APIs; if unavailable, hide unsupported platform controls while retaining local achievements and visual feedback |

Validate game, channel, schema/version and integrity before restoring; show a candidate and require player choice before replacing progress, keeping a backup. Reject wrong-game, future and test saves. Warn before overwriting cloud data. Guest success does not establish account-linked cross-device storage. If the host bridge is unavailable, provide a clear local-save fallback and show the actual storage location.

## Container and delivery

The iframe may disable outer scrolling. Use a real inner scroll region (`min-height:0; overflow-y:auto`), in-layout bottom controls and safe-area/dynamic-height handling. Use `touch-action:pan-y` in lists and scope gesture restrictions to the game area; do not disable all scrolling.

ZIP root is `index.html`. Exclude environment files, secrets, test fixtures, `.DS_Store` and `__MACOSX`. Verify permitted extensions and paths against the current [FAQ](https://open.4399.cn/docs/h5mini/faq.md). Package resources locally/inline except verified official links. Do not misclassify an SVG namespace URI as an external resource.

Shared rules include a 124×124 PNG icon, 300×200 JPG promotional image, 1080×1920 JPG video cover and description/controls of at most 300 characters each. Use the game's true orientation; do not apply a fixed portrait viewport to every game.

If video is selected, produce promotional/brand + real-gameplay video; otherwise defer it without requiring FFmpeg. 1920×1080 H.264/AAC is the workflow export default, not a verified platform limit. Video duration/size and screenshot count remain unverified; never reuse 233's 500 MB limit. An optional set of 4–5 screenshots is a preparation default, not a confirmed platform requirement.

After local preparation ask for AppID, ad/save permissions, rank configuration only if needed, then the upload test URL. No general frontend SecretKey requirement is established. Prioritize Xiaomi 8 / Android 10 in the required host (such as QQ when required by the platform), then other required browsers.

Sources: [ads](https://open.4399.cn/docs/h5mini/api/rewardad.md), [saves](https://open.4399.cn/docs/h5mini/api/archive.md), [ranking](https://open.4399.cn/docs/h5mini/api/ranking.md), [FAQ](https://open.4399.cn/docs/h5mini/faq.md).
