# 原生存储启动与恢复

用于已选的原生存储适配，尤其小红书；这是工程约束与异常验收矩阵，不是已交付的通用存储库。保留游戏 key、schema、进度与既有恢复策略，平台代码实施前核对[当前官方 API](https://miniapp-sandbox.xiaohongshu.com/minitool/doc)。

## 解析或写入前先确认存储状态

- 先取得并校验原生 key 的权威清单，再解释缺失 key。清单／读取失败是未知，不是空存储；缺失哨兵响应不能当有效恢复日志解析。
- 仅在清单已证明没有主档和恢复备份时，才可按已选的全新存储策略容忍已列出的空恢复标记（空字符串、JSON null、空对象）。这不是通用吞错；真实损坏的主档／日志／备份保留原始数据，提供重试／恢复，不自动删除。
- 有效原生存档不依赖可选的浏览器迁移。localStorage getter、枚举或读取不可用，不阻断已确认全新／有效的原生存储。启动迁移后须完整读取并校验候选再提交，部分读取不能提交部分存档；保留原件和渠道隔离。
- 未改变状态的启动恢复只读，不因启动成功重复写主档或 journal。按实际 SDK 合同区分 Promise 与回调结果；返回的请求 handle 不是业务响应。统一单次收口，每次写调用只执行一次，覆盖混合或重复通知。
- 写入校验回执与读回，失败／不一致时保留最新待保存进度；内存改变不能报已保存。保持可重试，不清 key，不丢 pending。
- 真读取失败后，可由玩家明确选择临时会话继续玩；所有持久化／原生写、迁移与自动备份均为零，界面说明进度未保存。只改提示不隔离写路径不算完成。

当前小红书合同区分 Promise 调用与回调调用（回调模式返回 undefined），`getStorage` 返回 data，`getStorageInfo` 返回 key 清单；加密参数一致，版本／方法可用性现场核对。历史请求 handle 与 mock 缺失形状只作兼容案例，不扩写成官方保证。

## 可选原生备份与浏览器启动

先按既有产品策略确认权威存储与可选备份。宿主元数据为空时，文件系统／云档／设备方法名称的存在不证明能力实际可用，也不能由此赋予未知数字码 `100` 官方含义。这不授权绕开状态不明的权威原生存储。

仅在既有策略允许浏览器为权威存储时，可选原生备份失败才可进入全新初始化分支。完整枚举游戏命名空间，包含 journal、pending 与备份。选定策略可要求全空，也可明确允许一份有限、逐项命名、严格校验取值 schema 且用途已核实的非进度偏好／安装元数据白名单。键名或单纯存在既不证明安全，也不证明有进度。承载进度或身份／谱系的存档、活动会话、pending 操作、journal、备份、非法辅助值及未知／未来 key 均不能据此通过。保留所有原始字节，不为满足条件清记录、重生成或重新绑定辅助标识。

对符合条件的快照，用未占用的一次性非游戏 key 验证实际写入、精确读回和删除，再将整个命名空间的键与原始值和原快照逐项比较。异常、空操作写入、读回／删除失败或并发变化均阻止选择；清理仅限本次探针的确切临时字节。仅探针成功不够：游玩／云启动前提交并读回初始档，再验证重开后身份与进度保留。本序列不是原子跨标签页锁。真实配额／安全拒绝仍可能阻止持久化，不能把内存标为已保存，也不承诺通用修复或新增后端。

保留已有、损坏或孤立的原生／浏览器记录及 journal、明确恢复／备份策略，以及账号／谱系／冲突／奖励／pending 操作保护。原生未知仍为未知，浏览器已就绪绝不授权自动用空档覆盖云进度。替身不代表真实宿主或受影响玩家验收，也不授权重新开放分发。

清单、已有档校验、写入、读回及清理诊断仅保留有界白名单阶段／错误类别，不含标识、原始值、本地路径或任意异常文本。测试替身或未观察到的玩家动作，不是该玩家真实根因的证据。

## 在目标真实实现上验证异常

只替换外部 SDK、浏览器存储、时钟和故障，执行真实启动、迁移、恢复与存档代码；断言写次数、保留字节、界面承诺与待保存进度，不只验证假 SDK 返回。

以下为后续目标实现的验收要求，不是文档维护的执行成绩。

| 输入／故障 | 必须观察到 |
| --- | --- |
| 原生全新清单，浏览器 getter 被禁 | 可开局，无强制迁移或启动写 |
| 有效原生主档，浏览器不可用 | 原生进度保留，不依赖浏览器 |
| 清单失败／格式错误 | 状态未知，不初始化空档或迁移 |
| 清单列有主档但响应缺 data | 保留读取失败，不虚构空档 |
| 空标记且无主档／备份 | 仅执行已选全新策略，未变状态启动零写 |
| 空标记但已有主档／备份 | 不丢现有数据 |
| 主档／journal／备份真实损坏 | 保留原始字节，记录阶段／版本并可重试 |
| 浏览器迁移只能读出部分数据 | 不部分提交，保留浏览器原件 |
| 事务中断且恢复数据有效 | 沿用既有事务恢复，不重复发奖 |
| 仅回调 API／返回请求 handle | 等业务回调，不将 handle 当响应 |
| Promise 与重复回调／错误 | 单次收口、单次预期写 |
| 写失败或读回不一致 | 未保存，最新 pending 保留 |
| 已选浏览器路径，命名空间全空或仅有严格有效辅助项 | 按明确策略／schema 判定，保留辅助字节及标识，再验初档提交与重开 |
| 进度／会话／pending／journal／备份、未知 key 或非法辅助值 | 阻止全新初始化，保留所有原始字节 |
| 探针期间命名空间变化、空操作写入或读回／删除失败 | 阻止选择，保留被改记录，仅清本次确切临时字节 |
| 初始档提交／读回失败，以及随后重开 | 确认提交前不称持久成功；成功重开保留相同身份／进度 |
| 真实配额或安全拒绝 | 保留实际失败与安全恢复，不虚构持久化、不清数据、不无条件转内存保存 |
| 诊断含任意／私密字段 | 只保留有界阶段／类别，不含标识、原始值、路径或异常载荷 |
| 读取失败后选择临时会话 | 所有持久写为零，不称已保存／有备份，可重试 |
| 旧包在真机失败 | 后续隔离测试不证明新包真机通过 |

来源版本／哈希、实际测试层和有界阶段诊断留项目证据。旧构建真实 iOS 启动失败仍有效，后续 mock 套件不关闭该问题；平台模拟器、Android／iOS 复测须绑定最新实际包后才可称原生验收通过。
