# 资源制作和交付

`<skill-dir>/assets/material-rules.json` 是尺寸/大小/字数的唯一机器规则表。它维护五个平台的已知上架字段，未知上限为空；字段和示例见[字段映射](listing-fields.md)。游戏包体另按[包体超限流程](package-budget.md)检查。默认导出设置不等于平台要求。正式交付核对官方或用户最新表单，无法访问则按已知要求制作并列未核验项，不阻塞不相关工作。

规则中已核实的平台要求才通过 `variants`、`count`、`codecs` 和已知字节上限阻断；`recommended_variants`、`recommended_count`、`recommended_codecs`、`recommended` 与 `recommended_ratio` 只提醒。`null` 表示该约束未知。4399 的 1920×1080 H.264 视频和预备 4–5 张详情截图属于工作室默认，当前后台要求仍须核实。

## 范围与可选视频

沿用[引导配置](guided-flow.md)中的物料选择，只处理选定范围。图文模式在 manifest 中写 `"processing": {"video": false}`，省略时也默认 false；明确选择视频才设 true。仅工程模式不执行物料流程。图文路径不查找、不安装、不调用 FFmpeg/ffprobe。

盘点工具通过 Python 读取 PNG/JPEG/WebP 尺寸，音视频仅登记文件与哈希；选择音视频检查后才使用 `--probe-av`。图片规格检查读取文件头，不等于完整像素解码，仍需查看成品。选择视频检查使用 ffprobe，剪辑和完整视频解码使用 ffmpeg。

关闭视频时，未处理的视频条目和缺失的视频/封面列在 `deferred`；`technical_status: pass` 仅表示本次已检查范围通过。存在暂缓项或失败时 `profile_complete: false`。不改平台原要求：必需视频保持待补，工程包和所选图文可以先交；两字段都不能代表当前后台或发布通过。原样复制已有视频也不能称已检查。

## 来源与图片

用 `inventory_project.py` 盘点根目录及 TapTap 资源，建立用途、源路径/哈希、源版本、方向、可复用/需转换/需重录/缺失映射。工具跳过依赖、备份、生成缓存、凭证和软链接；备份中有唯一资源时单独读该目录。它不决定“最新”、不自动改图。

优先当前确认品牌母版和实际画面，其次核对过的用户素材，再从当前渠道补录，最后生成缺比例宣传插画。不要以修改时间/文件名判权威。不同平台复用高清母版，分别导出。角色/标题留安全区，不生拉宽高比。图像编辑按当前图像工具要求；纯尺寸/编码导出遵守工具规则或用户明确授权。生成图仍需精确尺寸和目视验收。

详情首图可用宣传插画并标来源；其他“游戏截图”来自真实运行。旧截图可复用但标原版本，UI 变了就重截。等画布、字体、图片和入场效果结束，避开加载页、空画布、调试面板、黑屏、遮挡。

隔离浏览器/测试存档操作，展示解锁内容可用合法结构演示存档，记录起始进度；不动玩家档，不伪造游戏 UI。区分“浏览器实际运行”“平台客户端”“实体安卓录屏”。

## 视频

选择视频处理时，233、4399 输出一个**宣传/品牌内容 + 真实玩法操作**成片，不能仅交两个待拼文件。已有宣传片优先选合适片段；没有可用品牌画面做开场/结尾。

- 默认 1920×1080、30 fps、H.264、yuv420p、AAC、faststart，是兼容导出选择，非统一平台硬限制。
- 竖录可三屏并排或单屏居中留黑/品牌背景，保留比例与完整关键 UI，不用重复静帧凑实录。
- 根据内容安排宣传段、实录段和结尾，时长遵循当前平台要求。
- 只用授权音乐，区分原收音/后配乐。避开切页空白、无操作和停顿；保留正常速度与真实操作。
- 记录原片、源/成片时间区间、排布、配乐、源/目标版本及哈希。宿主/版本未知就标未知，不能把用户旧录像自动说成该渠道真机录像。
- ffprobe 后用 `ffmpeg -v error -i <video> -f null -` 完整解码，查看开场、实录中段、拼接前后、结尾，并实际试听播放。长作业异步执行并及时反馈。

## 输出与检查工具

每渠道交源码工程、游戏 ZIP（缺必需配置时仅预览）、独立物料 ZIP、可复制文案、上传顺序及来源/校验报告。物料 ZIP 主要放最终上传文件和必要说明，逐帧缓存/临时文件/测试档留制作区。可用本地预览页集中看，不另建部署系统。

按 `<skill-dir>/assets/material-manifest.example.json` 建最终映射，路径相对 manifest 所在目录，替换空值/示例路径。233 的 detail 必须 4–5 条；4399 依规格补齐角色。运行：

```sh
python3 <skill-dir>/scripts/verify_materials.py <manifest.json> --report <本轮证据目录>/materials-check.json
```

验证器检查文件内容格式、比例/尺寸/大小、必需角色/数量、字数、来源记录，MB 按十进制。它不会观看视频，不能认证真实性、品牌、字幕、声音或后台当前规则；`pass` 只代表已编码技术规则。人工、平台、真机结果单独记录。图片后缀与真实编码必须一致。
