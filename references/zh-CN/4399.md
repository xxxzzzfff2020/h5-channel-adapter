# 4399 H5 小游戏

使用 `window.h5api`，不是页游 `window.H5API`。交付时核对当前官方 SDK 和创作者后台要求；未知限额在共用规则中明确留空。

## SDK、能力与配置

官方脚本 `https://h.api.4399.com/h5mini-2.0/h5api-interface.php`，按官方文档在 body 内加载一次，使用时核对版本。

| 项目 | 处理 |
| --- | --- |
| AppID | 新游戏独立值；必填后才能出可上传正式候选包，初轮预览明确空配置 |
| 广告 | `h5api.playAd(callback)`；10000 开始，只有 10001 完整结束发奖 |
| 存档 | `h5api.save({type:'read'/'write', more:false, title, data})`；核对权限/返回协议 |
| 写档 | 官方要求手动触发，禁止游戏自动调用平台写档；至少 30 秒间隔 |
| 并发 | 串行处理未完成请求；遵循平台写入间隔，不自行给全部读操作加统一冷却 |
| 排行 | 原游戏需要且平台已建榜才启用；独立 rankId、分数含义/范围/排序；越界拒绝，不静默截断 |
| 成就/触感 | 核对当前 API；不支持时隐藏平台入口，保留本地成就及视觉反馈 |

按当前游戏核对 AppID，模板不内置实例 ID。广告申请中与已开通分开，代码接入不等于权限生效。

读档校验游戏/渠道/版本/结构/校验和，展示候选并由玩家确认再替换，保留本机备份，拒绝其他游戏、未来版本和开发测试档；写档提示覆盖。游客成功不描述为账号跨设备存档。

宿主桥不可用时提供明确的本地存档降级，并在界面说明实际保存位置；云档可用性按当前宿主检查。

## 容器、包与物料

iframe 可能 `scrolling="no"`，游戏内滚动区 `min-height:0; overflow-y:auto`，底栏在布局内，动态可视高度/安全区留白。滚动区 `touch-action:pan-y`，战场局部限制触摸，不能全局禁滚。选择器按工程，不硬套 `.main`。

ZIP 根目录 `index.html`；排除 `.DS_Store`、`__MACOSX`、环境配置/密钥、测试夹具。按 [官方 FAQ](https://open.4399.cn/docs/h5mini/faq.md) 检查扩展名/路径。扩展名清单以当前 FAQ 为准。运行资源随包或内嵌，只允许核实官方外链；SVG namespace 不是外链资源，避免粗糙扫描误判。

机器规格在 `<skill-dir>/assets/material-rules.json`：124×124 PNG 图标、300×200 JPG 宣传图、1080×1920 JPG 视频封面，介绍/操作说明各 ≤300 字。登记尺寸按实际游戏方向和后台字段设置，不统一强制竖屏。

交付合成宣传片/品牌内容+真实玩法视频。默认做 1920×1080 H.264/AAC MP4；视频时长/大小上限和截图张数待当前表单确认，**不把 233 的 500 MB 当 4399 规则**。先制作检查播放，未知上限列待后台确认，可预备 4–5 张实图，明确这是准备默认值。

## 初轮后所需

本游戏 AppID；广告/存档权限状态；需要排行才索取榜单 ID 和规则。上传后测试地址不阻塞本地出包。资质/隐私材料按真实必填字段索取，不编备案号、不宣称统一需要同一套证件。现有 H5 前端不需 SecretKey，不泛泛索取。

平台验证优先小米 8 / Android 10 / QQ，再按后台要求检查 UC 等入口。官方依据：[广告](https://open.4399.cn/docs/h5mini/api/rewardad.md)、[存档](https://open.4399.cn/docs/h5mini/api/archive.md)、[排行](https://open.4399.cn/docs/h5mini/api/ranking.md)、[FAQ](https://open.4399.cn/docs/h5mini/faq.md)。
