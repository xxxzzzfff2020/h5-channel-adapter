# 4399 H5 小游戏

使用 `window.h5api`，不是页游 `window.H5API`。交付时核对当前官方 SDK 和创作者后台要求；未知限额在共用规则中明确留空。

## SDK、能力与配置

官方脚本 `https://h.api.4399.com/h5mini-2.0/h5api-interface.php`，按官方文档在 body 内加载一次，使用时核对版本。

| 项目 | 处理 |
| --- | --- |
| AppID | 新游戏独立值；必填后才能出可上传正式候选包，初轮预览明确空配置 |
| 广告 | `h5api.playAd(callback)`；10000 开始，只有 10001 完整结束发奖 |
| 存档 | `h5api.save({type:'read'/'write', more:false, title, data})`；核对权限/返回协议 |
| 写档 | 官方要求手动触发，禁止游戏自动调用平台写档；至少 30 秒间隔 |
| 并发 | 串行处理未完成请求；遵循平台写入间隔，不自行给全部读操作加统一冷却 |
| 排行 | 原游戏需要且平台已建榜才启用；独立 rankId、分数含义/范围/排序；越界拒绝，不静默截断 |
| 成就/触感 | 核对当前 API；不支持时隐藏平台入口，保留本地成就及视觉反馈 |

按当前游戏核对 AppID，模板不内置实例 ID。广告申请中与已开通分开，代码接入不等于权限生效。

读档校验游戏/渠道/版本/结构/校验和，展示候选并由玩家确认再替换，保留本机备份，拒绝其他游戏、未来版本和开发测试档；写档提示覆盖。游客成功不描述为账号跨设备存档。

宿主桥不可用时提供明确的本地存档降级，并在界面说明实际保存位置；云档可用性按当前宿主检查。

## 容器、包与物料

iframe 可能 `scrolling="no"`，游戏内滚动区 `min-height:0; overflow-y:auto`，底栏在布局内，动态可视高度/安全区留白。滚动区 `touch-action:pan-y`，战场局部限制触摸，不能全局禁滚。选择器按工程，不硬套 `.main`。

ZIP 根目录 `index.html`；排除 `.DS_Store`、`__MACOSX`、环境配置/密钥、测试夹具。按 [官方 FAQ](https://open.4399.cn/docs/h5mini/faq.md) 检查扩展名/路径。扩展名清单以当前 FAQ 为准。运行资源随包或内嵌，只允许核实官方外链；SVG namespace 不是外链资源，避免粗糙扫描误判。

Owner 或平台反馈游戏包不合规范但未给具体失败项时，记录拒绝结果并保留原因未知；取得实际报错后才判断分辨率、包名或 ZIP 层级。本地静态通过不等于平台规范通过，内容哈希相同的改名不是合规修复。Owner 自行修正的产物须取得实际新文件并复查后再报通过，不覆盖其现场，也不沿用旧回执认定修好。

Owner 报告已上传修正包时，区分转述、独立后台核验与规范验收；未取得实际上传制品／版本／SHA-256 就保留未知，不能将旧本地候选哈希当作线上身份。本地 SDK 接入观察仅对应该候选，不能单凭缺项推断拒审原因或获得新增接入授权；收到具体审核反馈后才针对修改游戏。

### 上架文案中的游戏分辨率

**2026-10-12** 重新读取[官方 FAQ](https://open.4399.cn/docs/h5mini/faq.md)：游戏尺寸需控制在 **800×600 以内**，并添加屏幕自适应。这是游戏运行尺寸要求，不是宣传图片／视频分辨率限制。今后每份 4399 上架文案必须明确后台建议的**游戏宽、高、横屏／竖屏**，说明布局依据和实际自适应验证状态。按当前游戏布局和当前表单另行推荐，不把某个游戏的竖屏尺寸设成统一默认值。使用[上架文案模板](../../assets/listing-copy.4399.example.md)，将游戏分辨率与物料规格分节填写。

### 物料限制与复查

机器规格在 `<skill-dir>/assets/material-rules.json`：124×124 PNG 图标、300×200 JPG 宣传图、1080×1920 JPG 视频封面，介绍／操作说明各 ≤300 字。**2026-10-12 Owner 当前后台反馈**视频封面不超过 **500K**，机器表保守按 **≤500,000 字节**阻断；这不是平台已确认的精确字节定义。仅适用于 `video_cover`，图标、宣传图及详情截图的字节上限分别待核实。竖版视频封面不决定游戏横竖屏。

交付前对实际文件运行物料校验，同时检查尺寸和真实字节数；尺寸正确但封面超限必须 fail，即使未选择视频处理但提供了封面也须检查。在已授权物料工作内保护原件、修复候选，再以新哈希／报告复查后才报通过。Owner 自行处理时，未拿到新文件前保持待验；技术检查不替代解码、画面及当前表单验收。

选择视频处理才制作合成宣传片/品牌内容+真实玩法视频；否则暂缓，不要求 FFmpeg。默认做 1920×1080 H.264/AAC MP4；视频时长/大小上限和截图张数待当前表单确认，**不把 233 的 500 MB 当 4399 规则**。先制作检查播放，未知上限列待后台确认，可预备 4–5 张实图，明确这是准备默认值。

## 初轮后所需

平台验证优先小米 8 / Android 10 / QQ，再按后台要求检查 UC 等入口。官方依据：[广告](https://open.4399.cn/docs/h5mini/api/rewardad.md)、[存档](https://open.4399.cn/docs/h5mini/api/archive.md)、[排行](https://open.4399.cn/docs/h5mini/api/ranking.md)、[FAQ](https://open.4399.cn/docs/h5mini/faq.md)。

## 主上传字段与成品品牌文案

Owner 转交的 2026-10-12 后台只读快照要求根入口 index.html，上传文件名允许英文、括号、数字、下划线和连字符；采用简短保守 ASCII ZIP 名，仅扩展名前用点。预检检查上传文件名，不将它扩张为统一重命名包内资源规则。主游戏文件字段显示单文件 2G，机器表的保守字节换算仅对应此字段，不套到图片／视频；这些观察仍不能解释之前包被拒的具体原因。
