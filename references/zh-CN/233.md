## 能力与广告

- 本工作流按**无平台云存档**适配。去除 TapTap 云同步调用、自动读写、恢复入口与宣传承诺，保留本机自动保存、离线收益、已有备份/导入/损坏恢复。不要顺带删除本地成就、视觉震屏或旧存档兼容字段。
- 平台排行、成就、触感、账号、支付按实际能力和本轮范围声明。两案例未启用不证明平台永远没有这些能力；未经核实不复用 TapTap 接口，也不新增原游戏没有的系统。
- IAA SDK：`https://cdn.233xyx.com/h5ad/metah5ad_v1.min.js`，普通脚本，全局 `MetaH5Ad`。2026-09-22 GET 200；获取成功不等于真实广告通过。
- 使用 `MetaH5Ad.isAdSupport(1, callback)`、`MetaH5Ad.showAd(1, callback)`。案例接口不收前端 AppID 参数，应用身份由宿主提供；仍需后台建应用和关联测试，不能写成无需建项。
- 只认归一化后的 `code === 0 && data.status === 4` 完成。旧 payload 兼容须有真实样本/SDK 依据，不接受任意 `success:true`。展示 0、点击 3、关闭/跳过/失败/超时/未知态均不发奖。
- 原生回调无交易 ID：游戏请求/奖励收据去重，取消或超时后旧广告未结束时不复用回调槽，避免迟到回调串账。按真实关闭协议释放，不照抄某游戏的超时秒数。
- 完成但写盘失败时沿用事务/重试保护，不重复奖励或强制再看一次。广告前后恢复暂停/音频；SDK 缺失不阻塞普通玩法。

## 构建

- ZIP 根目录 `index.html`，校验真正 ZIP 的 CRC、相对资源、入口和逐文件哈希。
- 两案例只允许官方 `*.233leyuan.com`、`*.233xyx.com` HTTPS 脚本，实际用精确 URL 白名单。后缀必须核对域名边界，不能接受 `233xyx.com.evil.example`；新域名需依据。游戏图片/音视频优先随包。
- 不注入用户 SDK 占位地址 `.../mta-h5-api.js`。实际需要登录时再查真实 URL/模块格式；案例用户 SDK 启用时为 `type="module"`，与 IAA 普通脚本不同。
- 如需官方 SVG helper，必须实际加载测启动。案例 A `<svg>` 缺 `xmlns="http://www.w3.org/2000/svg"` 曾触发 XML 解析异常；检查动态模板，mock 通过不能代替真实脚本启动验证。
- 排除 TapTap SDK/云调用、其他项目 ID 与 QA 入口，保留许可证。沿用项目构建，不要求 Vite。
