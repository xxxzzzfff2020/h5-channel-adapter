# 新平台与经验修订

平台分“已有项目经验”“文档已核对、待首个项目验证”“规则未取得”。有文档不等于运行通过；未经代表项目验证的平台仅显式选择启用，不纳入默认“全部已支持”。

1. 确认正式产品、H5/原生路线、官方文档/SDK/后台与实际制品，不混淆同名产品。
2. 同步维护英文与 zh-CN 平台参考，记录链接、日期、能力/身份/打包/物料规则、未知项、宿主验证路径。
3. 准备支持自动检查时，将已核实规格加入共用 material-rules.json。未知值 null+说明，不套其他渠道上限。仅真实新格式/语义需要时扩验证器并测行为。
4. 注册 SKILL 入口并区分初轮/次轮字段：公开 ID、服务端密钥、权限、登录、上传后测试 URL 不是一回事。
5. 默认小米 8/Android 10；单独核宿主内核，同时检查 [系统兼容](portability.md)。
6. 隔离演练缺配置、缺视频和已有渠道更新；保护来源/存档，继续独立工作，准确报告未知。运行 Skill 格式检查与受影响工具测试。

不放私有任务 ID、个人绝对路径、游戏源码、大媒体、凭证、预览 token。官方 Skill/CLI/MCP 用 [上游机制](upstream-tools.md) 独立获取和更新；不复制改造，远程安装器建议的全局路由/发布动作不等于用户授权。

中英文同步更新，机器规格唯一维护；行为变更记录 CHANGELOG 与版本。经验依据是实证，不是修改时间；仅补文档时不重做旧游戏或发布。
