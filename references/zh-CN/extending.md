# 新增与维护平台

平台说明负责把共用流程接到一个具体发布产品。只保留适配时需要的决策信息：运行环境、打包方式、平台能力、上架字段与配置步骤。

1. 确认正式产品、H5/原生路线、官方文档、SDK 和创作者后台，不混淆同名产品。
2. 添加对应的英文和中文说明，附官方链接与日期。写清初轮准备、必需配置、可选能力、打包和宿主测试入口；未知要求明确列出。
3. 已知物料与包体限制写入共用 JSON，区分推荐值和硬限制，不套用其他平台数值。只有新格式或行为需要时才扩展辅助工具。
4. 在 `SKILL.md` 和 README 平台表注册入口，在 `assets/platform-sources.json` 登记官方工具。区分公开 ID、账号访问、权限状态和服务端安全配置。
5. 命令兼顾 macOS 和 Windows；遵循项目安卓目标，单独核对宿主内核要求。
6. 用可复现的小项目检查流程：缺配置仍能完成独立准备，原工程和存档保持完整，不支持的能力有明确说明。可执行行为变化时运行相关工具测试。

官方 Skill、CLI、MCP 按[上游机制](upstream-tools.md)独立使用和更新，不在本仓库维护修改副本。平台说明不能授权上传、账号变更或新收费服务。

中英文同步维护，机器规则只保留一个来源，影响使用方式的变化记录在 `CHANGELOG.md`。私有项目历史及专属 ID、数值、素材不进入 Skill。贡献流程见[贡献指南](../../CONTRIBUTING.zh-CN.md)。
