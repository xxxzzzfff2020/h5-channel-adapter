# H5 可靠性合同与验收配方

这是可复用工程建议，**不是平台规范或已交付公共模块**。先检查目标源码、存档／经济规则和当前官方接口，再只采用已选范围。已有稳定架构不为统一而重写；项目 ID、槽名、数值、超时及历史通过数量不进入公共规则。

## 身份、本地存档与云

- 身份未知时可在隔离本机作用域继续游戏，冻结账号云档、排行榜和成就写入。网络恢复不是身份确认；账号、云 UUID、本地 key、存档谱系、请求 generation 分开。
- 所有存储访问容错，包括取得 `localStorage` 对象、读取启动偏好和写入。内存游玩、本机持久化、云同步分别显示。候选校验后提交；迁移／导入／云覆盖前保留可校验备份。checksum 是检错，不是反作弊；旧客户端不能覆盖未来 schema。
- 奖励与完成回执同一事务提交。保存失败回滚，或保留不可重复消费的“奖励已确认、待保存”恢复状态；内存变化不能报持久化成功。权威槽已提交时，兼容镜像失败不推翻它。
- 云启动单飞；超时、重置、切号后的回调用 generation／settled-once 隔离。读取失败不是空云；A 切 B 空云不能把 A 本地档写给 B。保留已有手动／自动同步产品决策。
- 同谱系且先后关系可证才自动对账；分叉展示差异让玩家选，覆盖先备份。余额较大、时间戳较新、不同设备 revision 不能单独判胜。使用平台返回 UUID；创建回执缺失先重读核对，不盲目重建。
- UI 取消／Promise 超时只使本地结果失效，已发远端写可能成功。保留结果未知、重读后再写，不重叠重试。客户端预检、lease、读 revision 再写都不是服务端 CAS 或原子锁。
- 主档与诊断共用配额时统一仲裁、主档优先；合并最新待写状态，真正提交前序列化。按当前官方配额和错误类型设置有界重试／退避，两个独立限频器不等于共享预算。

**验收：**getter/read/write 抛错、配额耗尽、读回不一致、主／备档损坏、未来 schema、旧档迁移、多窗口轮流写、奖励写失败与刷新恢复。云另测双真实账号／会话／设备、空云／旧云／分叉、请求中切号、创建回执缺失、超时后实际写成功、诊断竞争。替身测试不能关闭真实账号门，破坏性测试使用隔离测试档。

## 离线、签到与广告

三者分别属于产品合同，不因平台有云或广告就全部添加。

- 冷启动与同会话回前台共用离线结算；时间高水位保证区间只推进一次，覆盖回拨、连续回归、午夜和上限。保留原经济 gate 与超限丢弃规则。
- 有待领收益时分时间、资金、广告三本账：旧未领不能冻结工程／时间或丢新钱。直接入账项目不强加 carried-money。广告隐藏时间不重复算离线，返回重置帧钟。
- 签到先定时区、连续／累计、首日资格与结束条件；奖励、标记、次数一起落盘。同谱系回旧档保留防重复水位，不按 max 或相加合并余额。日界线／活动版本变更要迁移；日常任务与广告配额独立。本机时钟防回拨不是可信服务器时间。
- 广告生命周期：资格 → 固定目标和唯一尝试 ID → 若产品要求刷新恢复则保存 pending → 播放 → 只接受当前账号／请求／目标的官方明确成功终态 → 奖励和回执一起保存 → 提示已到账。不按时长、失焦、倒计时猜成功；可重置日计数不能当唯一 ID。迟到／重复／取消／失败／无回调不额外发奖。明确刷新边界，单机去重不能承诺跨设备 exactly-once。

**验收：**旧回执加新离线区间、分段与整段结算、同日多次广告、pending 目标变化、重复／迟到／取消／不回调、pending 与奖励写失败、刷新与声音恢复；日界线迁移、回旧档、回拨与跨账号隔离。

## 排行榜

固定榜单 ID、整数指标／范围、编码版本、方向、同分、覆盖／合并与资格。超大财富不强转不安全 JS Number，不暗加小数排序。测试／调试／特殊导入档明确资格；未知身份禁提交。

状态按账号、saveId 和榜命名空间隔离；换榜必须能首投。成功回调只确认本次快照，不能清掉提交中新增的待交值。历史最佳榜和当前状态榜不能一律 max。切号、换档、换榜使旧 generation 失效，排队／同步／成功／失败／超范围／不支持状态如实表达。

**验收：**边界／非法值、同分／升降分、新榜首投、提交中变分、永久无回调、旧回调、恢复重试、真实读回、昵称／头像／本人行。打开榜单不等于成绩上榜，客户端成绩不等于服务端权威或反作弊。

## 音乐、音效与设置

- 统一控制器管理用户意愿、场景、后台／广告和实际后端。长 BGM 可复用原生媒体元素，短 SFX 可用 WebAudio；已有稳定后端先测量，不机械替换。编码码率不等于解码 PCM 内存。
- 首次手势直接发起 play；旧播放 Promise／资源事件隔离，自动播放拒绝等待新手势。意外停滞有界恢复，不无限新建上下文或重载；加载 `suspend` 不是暂停证据。音量 0／muted、设置暂停、广告临时降音分别管理。
- 固定合成循环可把**本项目自有旋律**预渲染，解除对 rAF 补排的依赖；保留尾音并试听接缝。动态作曲、逐音交互、严格音游同步另设计；不强制某种格式、秒数、采样率。
- 循环时钟回零是进展。主线程阻塞测试应在后续事件循环任务读媒体时钟，处理回零并观察新合成节点；时间推进／running 不等于扬声器无断音。诊断不能主动解锁音频改变故障现场。
- 音乐／音效开关音量独立，偏好保存失败有反馈；云恢复时偏好随档还是随设备要明确。手势、焦点、广告返回尊重静音／暂停。字号覆盖按钮、弹窗、Canvas、长文案和最大字号窄屏；字体加载失败用可读 fallback，字号支持不能证明任意字体家族切换。
- 省电／减少动效只改变表现，不改变经济或模拟。振动不可用安全降级；重置设置、重开、删本机档、删云档分别表达。

**验收：**冷启动、首次手势、切场景／曲目、完整循环与接缝、静音／0 音量、暂停／恢复／刷新、保存失败、play 拒绝／停滞、旧 Promise、加载失败、广告成功／取消、后台／锁屏／来电、最大字号窄屏。真实 iOS／Android 宿主试听及长时运行独立记录；一个历史手机试听不能认证另一个项目。

## 启动、布局、性能与诊断

独立最小 HTML 错误页覆盖模块下载／解析、同步／异步初始化和超时，显示构建／错误码，重试仅 reload 不删档。可操作 UI 或云预检建立后撤守卫。构建 target 不会补齐全部 DOM／Intl／存储 API。同源 HTTP 预览才适合验证构建；file:// 开发源码打不开不是玩家故障根因。

Viewport、DPR、渲染缩放、安全区和输入逆变换共用合同，避免重复乘 DPR 或把 Maker NanoVG API 贴入 DOM／Canvas。一次事件用一致快照。测窄屏／长屏／平板、安全区、最大文字、旋转与实际点击区域。合成输入去重与权益幂等分开，核对运行时事件而非任意 debounce。

用新档、中期、高进度档测量；区分 JS／布局／绘制／输入与产品节奏。先减少重复模型、DOM 读写和强制布局；展示可缓存，交易仍用最新状态校验。表现限频／滚动让路不得暂停模拟、保存或丢结构同步。**同一页面实例**跑首次解锁、转阶段、重生、入口重现和后期，逐阶段刷新会掩盖 hidden 状态残留。不要统一规定帧率，或据 FPS 截图断言设备唯一根因。

诊断是有界可选旁路：独立 schema／槽，不参与游戏恢复；UUID 由平台分配；字段白名单、有界字符串／计数、完整包装后 UTF-8 字节门。只记录构建、可用宿主／设备字段和小摘要；不含 UID、存档正文、token、签名 URL、任意异常 payload 或无限事件日志。缺字段省略。主档优先和共享配额仍适用，失败不阻断主流程；游戏中明确用途、访问和保留规则。不承诺主模块启动前或系统杀页后的故障必有日志。

**验收：**缺 API／模块／资源、入口前存储异常、同步／异步错误、不删档恢复；实际布局输入与同实例结构生命周期；中文／emoji 体积、序列化／文件写错、不回调、共享配额、切号、首次创建竞争和诊断失败旁路。
