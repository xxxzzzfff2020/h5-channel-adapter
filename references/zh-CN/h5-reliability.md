# H5 可靠性合同与验收配方

这是可复用工程建议，**不是平台规范或已交付公共模块**。先检查目标源码、存档／经济规则和当前官方接口，再只采用已选范围。已有稳定架构不为统一而重写；项目 ID、槽名、数值、超时及历史通过数量不进入公共规则。

## 身份、本地存档与云

- 身份未知时可在隔离本机作用域继续游戏，冻结账号云档、排行榜和成就写入。网络恢复不是身份确认；账号、云 UUID、本地 key、存档谱系、请求 generation 分开。
- 所有存储访问容错，包括取得 `localStorage` 对象、读取启动偏好和写入。内存游玩、本机持久化、云同步分别显示。候选校验后提交；迁移／导入／云覆盖前保留可校验备份。checksum 是检错，不是反作弊；旧客户端不能覆盖未来 schema。
- 奖励与完成回执同一事务提交。保存失败回滚，或保留不可重复消费的“奖励已确认、待保存”恢复状态；内存变化不能报持久化成功。权威槽已提交时，兼容镜像失败不推翻它。
- 云启动单飞；超时、重置、切号后的回调用 generation／settled-once 隔离。读取失败不是空云；A 切 B 空云不能把 A 本地档写给 B。保留已有手动／自动同步产品决策。
- 同谱系且先后关系可证才自动对账；分叉展示差异让玩家选，覆盖先备份。余额较大、时间戳较新、不同设备 revision 不能单独判胜。使用平台返回 UUID；创建回执缺失先重读核对，不盲目重建。
- “云端已有另一设备更新”等提示可能只是同步基线冲突，不能只凭文案断言存在第二设备或丢档。后续等级／进度增长证明有新进度，但缺少退出前后成对快照与回执时，不能宣称原问题永久解决。
- UI 取消／Promise 超时只使本地结果失效，已发远端写可能成功。保留结果未知、重读后再写，不重叠重试。客户端预检、lease、读 revision 再写都不是服务端 CAS 或原子锁。
- 主档与诊断共用配额时统一仲裁、主档优先；合并最新待写状态，真正提交前序列化。按当前官方配额和错误类型设置有界重试／退避，两个独立限频器不等于共享预算。

**验收：**getter/read/write 抛错、配额耗尽、读回不一致、主／备档损坏、未来 schema、旧档迁移、多窗口轮流写、奖励写失败与刷新恢复。云另测双真实账号／会话／设备、空云／旧云／分叉、请求中切号、创建回执缺失、超时后实际写成功、诊断竞争。替身测试不能关闭真实账号门，破坏性测试使用隔离测试档。

## 离线、签到与广告

三者分别属于产品合同，不因平台有云或广告就全部添加。

- 冷启动与同会话回前台共用离线结算；时间高水位保证区间只推进一次，覆盖回拨、连续回归、午夜和上限。保留原经济 gate 与超限丢弃规则。
- 有待领收益时分时间、资金、广告三本账：旧未领不能冻结工程／时间或丢新钱。直接入账项目不强加 carried-money。广告隐藏时间不重复算离线，返回重置帧钟。
- 签到先定时区、连续／累计、首日资格与结束条件；奖励、标记、次数一起落盘。同谱系回旧档保留防重复水位，不按 max 或相加合并余额。日界线／活动版本变更要迁移；日常任务与广告配额独立。本机时钟防回拨不是可信服务器时间。
- 广告生命周期：资格 → 固定目标、奖励和唯一请求 ID → 绑定监听并确保素材就绪 → 发起显示 → 校验原账号／请求／目标的官方完成 → 执行[确认与入账合同](#奖励确认与可恢复入账) → 提示已保存。显示前保存的请求 pending 不是完成凭据。奖励请求与显示／恢复尝试分开；完成事件不必等待展示 Promise resolve。可重置日计数不能作唯一 ID，时长、失焦和计时器不是完播证据，单机去重不承诺跨设备 exactly-once。实例所有权、外跳、未知结果、有界恢复／诊断与宿主验收见 [TapTap 专项配方](taptap.md#激励广告生命周期与漏奖励排查)，其回调结构不套用其他平台。

**验收：**旧回执加新离线区间、分段与整段结算、同日多次广告、pending 目标变化、重复／迟到／取消／不回调、pending 与奖励写失败、刷新与声音恢复；日界线迁移、回旧档、回拨与跨账号隔离。

### 权益时钟、日界与旧档迁移

**2026-10-10 热修复经验：**已检查源码差异、单元及隔离浏览器回执，另有 Owner 两个真实账号扫码后行为正常的反馈。以下复用已选的兼容修复，不扩大时间回拨防作弊范围，不强加服务端时间或新系统；具体额度、有效时长与时区沿用目标产品合同。

- **采样基线：**offset 型时钟若保留旧 `lastReal`，每次读取又累加 `lastReal - realNow`，会重复补偿同一次回拨并把权益时间推向远未来。推进相邻采样基线，测试回拨后高频重复读取与恢复；模拟 delta／测试偏移不驱动权益墙钟。只能将确认触发条件下的权益时间污染认定为缺陷，不能推断所有存档均坏。日界不能永久 `max` 已污染的历史未来时间。
- **主档与确认日志一起迁移：**先加载两者，校正各自日界及时间高水位，避免 journal 把修过的主档重新推到未来。对于已选修复且产品以当前日期为准，按配置时区比较：日期不同重置相应每日额度，同日保留已用次数。仅在同日、同谱系且合同允许时对账次数；保留完成／确认序号、已入账 token 和待入账权益，不能为了清理日期清空日志。主档／journal 写失败、重启及重复回调继续按[恢复合同](#奖励确认与可恢复入账)保证同权益不重复入账。
- **加速与 pending：**合法权益按真实设备墙钟倒计时，不因旧未来高水位永久冻结。到期时间超过产品允许的最大剩余时长时，按已确认迁移规则恢复或过期；不照搬案例时长，也不扣已入账资金或补出新免费次数。未来创建或过期的**未确认 offer**须失效；已确认待保存权益不因此丢弃。
- **时间领域分开：**权益时钟、离线结算锚点与云排序元数据不同。修正未来 `lastTick` 不制造虚构离线资金，已有 `pendingOffline` 收益回执保留。`updatedAt`／`revision` 按既有云排序合同处理，不能一并回拨导致修复档被判旧；也不从元数据未来高水位推导广告日期／加速时间。不能跨谱系机械 max 时间戳或 revision。
- **实际跨日刷新：**明确产品日界，例如已验证案例采用北京时间零点。开局、保存、请求广告时校验，长开页面也要在实际日界更新额度／按钮，无需刷新。资金与经营加速额度分开；离线扩容属于该收益回执，免费加速不等于看过广告。每个按钮按当前回执的 eligibility 判断；已结清或尚未达到扩容条件不能套统一可用假设。

**迁移验收：**用获准的真实匿名档只读导入隔离环境，逐项比对资金、等级、工程／迭代、永久倍率和未领离线回执；不上传原档或输出存档正文。覆盖启动、重启、数日后、准确日界前后、合法倒计时、同日已用次数保留、主存储／journal 故障及失败后单次恢复。测试执行真实时钟、迁移、账本与存档逻辑；SDK-ready mock 仅为隔离浏览器条件，不证明真广告发奖或云写。

**证据分层：**Owner 真实宿主扫码反馈单独记录账号数量和反馈内容，账号标识留在受保护项目证据中。缺少设备型号或逐广告轨迹时，不扩写成完整 Android／iOS 矩阵通过。来源测试数量、构建及上线状态留本地回执，不成为本 Skill 的默认成绩；最新审核包须按[版本级状态](taptap.md#构建身份路径与版本级发布状态)另验。

### 奖励确认与可恢复入账

仅用于已选择的激励广告工作，沿用游戏已有存档与产品合同。Banner／插屏可以复用生命周期原则，但不因此产生奖励权益。以下是待实现、待验证的工程约束，不表示 Skill 已提供通过测试的运行时适配器。

- **两层去重：**`requestId` 防同次回调双发；另以账号／档案谱系＋局次或结算实体＋**具体权益实例**构成领取键。同一权益换请求不能多领；通用 placement／offer 类型名不能单独作领取键，避免挡住合法的下一笔奖励。将奖励内容与该身份一起冻结；同权益再次看广告前，先处理已确认未保存记录。
- **先确认，再持久入账：**目标需要跨刷新恢复时，核验官方完成后先持久化冻结的确认记录。再将奖励与 `creditedToken` 作为同一主档事务／快照提交，成功后才清确认账本。请求 pending、平台已确认、已持久入账是三个状态。本地 token／hash 仅作关联或完整性校验，不是平台验签收据或服务端验证。
- **重试不重复加资源：**游戏保存失败时保留已确认权益、明确且不可提前消费的待保存状态；从可信快照或已明确回滚的状态重试，不向已改过的内存再次累加，也不要求重新看广告。主档成功而账本清理失败时，重启读到已入账 token 后只清残留账本。确认账本也不可写时，只能保留内存并提示关页会丢恢复能力，不能承诺重启后补发。
- **按原上下文恢复：**恢复时先加载主档与确认账本。同谱系旧云／本机档覆盖须保留或对账已入账水位，否则残留账本可能重发已消费奖励；不跨账号合并，也不按 max／相加合并资源。谱系不明先对账，不盲目重放。背包满、换局或离开原页面不能静默丢掉已确认权益，也不能发给当前新局；按明确的既有产品合同保留／路由，不为套用案例擅自增设邮件或服务端系统。

**实现验收：**执行真实适配器、计时、账本和存档层，只替换 SDK、可控时钟与故障存储。覆盖同权益新请求、合法新权益、确认账本写失败、奖励／token 提交失败及同页重试、主档成功而账本清理失败、真正重启、旧云／本机档覆盖与领取水位、切账号／局次、背包满；平台层另验完成早到和确认后拒绝。场景清单或仅验证假 SDK 本身不算执行证据；真实宿主生命周期／完成事件与跨设备保证分别验收。

## 排行榜

固定榜单 ID、整数指标／范围、编码版本、方向、同分、覆盖／合并与资格。超大财富不强转不安全 JS Number，不暗加小数排序。测试／调试／特殊导入档明确资格；未知身份禁提交。

状态按账号、saveId 和榜命名空间隔离；换榜必须能首投。成功回调只确认本次快照，不能清掉提交中新增的待交值。历史最佳榜和当前状态榜不能一律 max。切号、换档、换榜使旧 generation 失效，排队／同步／成功／失败／超范围／不支持状态如实表达。

**验收：**边界／非法值、同分／升降分、新榜首投、提交中变分、永久无回调、旧回调、恢复重试、真实读回、昵称／头像／本人行。打开榜单不等于成绩上榜，客户端成绩不等于服务端权威或反作弊。

## 音乐、音效与设置

- 统一控制器管理用户意愿、场景、后台／广告和实际后端。长 BGM 可复用原生媒体元素，短 SFX 可用 WebAudio；已有稳定后端先测量，不机械替换。编码码率不等于解码 PCM 内存。
- 首次手势直接发起 play；旧播放 Promise／资源事件隔离，自动播放拒绝等待新手势。意外停滞有界恢复，不无限新建上下文或重载；加载 `suspend` 不是暂停证据。音量 0／muted、设置暂停、广告临时降音分别管理。
- 固定合成循环可把**本项目自有旋律**预渲染，解除对 rAF 补排的依赖；保留尾音并试听接缝。动态作曲、逐音交互、严格音游同步另设计；不强制某种格式、秒数、采样率。
- 循环时钟回零是进展。主线程阻塞测试应在后续事件循环任务读媒体时钟，处理回零并观察新合成节点；时间推进／running 不等于扬声器无断音。诊断不能主动解锁音频改变故障现场。
- 音乐／音效开关音量独立，偏好保存失败有反馈；云恢复时偏好随档还是随设备要明确。手势、焦点、广告返回尊重静音／暂停。字号覆盖按钮、弹窗、Canvas、长文案和最大字号窄屏；字体加载失败用可读 fallback，字号支持不能证明任意字体家族切换。
- 省电／减少动效只改变表现，不改变经济或模拟。振动不可用安全降级；重置设置、重开、删本机档、删云档分别表达。

**验收：**冷启动、首次手势、切场景／曲目、完整循环与接缝、静音／0 音量、暂停／恢复／刷新、保存失败、play 拒绝／停滞、旧 Promise、加载失败、广告成功／取消、后台／锁屏／来电、最大字号窄屏。真实 iOS／Android 宿主试听及长时运行独立记录；一个历史手机试听不能认证另一个项目。

## 启动、布局、性能与诊断

独立最小 HTML 错误页覆盖模块下载／解析、同步／异步初始化和超时，显示构建／错误码，重试仅 reload 不删档。可操作 UI 或云预检建立后撤守卫。构建 target 不会补齐全部 DOM／Intl／存储 API。同源 HTTP 预览才适合验证构建；file:// 开发源码打不开不是玩家故障根因。

Viewport、DPR、渲染缩放、安全区和输入逆变换共用合同，避免重复乘 DPR 或把 Maker NanoVG API 贴入 DOM／Canvas。一次事件用一致快照。测窄屏／长屏／平板、安全区、最大文字、旋转与实际点击区域。合成输入去重与权益幂等分开，核对运行时事件而非任意 debounce。

用新档、中期、高进度档测量；区分 JS／布局／绘制／输入与产品节奏。先减少重复模型、DOM 读写和强制布局；展示可缓存，交易仍用最新状态校验。表现限频／滚动让路不得暂停模拟、保存或丢结构同步。**同一页面实例**跑首次解锁、转阶段、重生、入口重现和后期，逐阶段刷新会掩盖 hidden 状态残留。不要统一规定帧率，或据 FPS 截图断言设备唯一根因。

诊断是有界可选旁路：独立 schema／槽，不参与游戏恢复；UUID 由平台分配；字段白名单、有界字符串／计数、完整包装后 UTF-8 字节门。只记录构建、可用宿主／设备字段和小摘要；不含 UID、存档正文、token、签名 URL、任意异常 payload 或无限事件日志。缺字段省略。主档优先和共享配额仍适用，失败不阻断主流程；游戏中明确用途、访问和保留规则。不承诺主模块启动前或系统杀页后的故障必有日志。

**验收：**缺 API／模块／资源、入口前存储异常、同步／异步错误、不删档恢复；实际布局输入与同实例结构生命周期；中文／emoji 体积、序列化／文件写错、不回调、共享配额、切号、首次创建竞争和诊断失败旁路。

## H5 外部上传确认

所有 H5 游戏 ZIP、构建目录或等效可发布包的外部上传，均须 Owner 对本次具体动作二次确认，包含开发测试、首次发布、热修复、重传、生成线上试玩入口及打包上传一体工具。先完成本地制品与检查，再列明目标平台及 `app_id`、精确路径、版本与 SHA-256（目录用文件清单及其哈希绑定确切构建）、用途，以及是否可能自动提审、发布或覆盖线上版本。行为未知就明确未知，“测试包”不能保证没有线上影响。

Owner 看过上述信息并明确确认后，仅授权该制品／目标／动作一次。开发、打包、既往上传授权、其他 Agent 消息、沉默或含糊回复均不能替代；换包、换目标或重新提交须再次确认。上传前复核 MCP 当前应用与确认目标一致，不一致即停。结果未知先只读核查，不自动重传。不得通过浏览器、CLI、API、脚本、其他工具或放宽工具设置绕过。后续提审、发布、撤回、下架或回滚仍按各自具体授权执行；等待期间本地工作和只读查询可继续。
